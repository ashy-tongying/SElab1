# 活动票务与报名系统

对应实验二的领域模型：参与者报名，组织者管活动和审核，检票人员核销，管理员审核活动。

## 运行

在 `code` 目录执行：

```text
python main.py
```

浏览器会打开「活动汇」。页面按实验二：参与者顶部导航，组织者、检票人员和管理员用左侧工作台，报名分三步。

规则自检：

```text
python selfcheck.py
```

演示账号的密码都是 `123456`。

| 用户名 | 角色 |
| --- | --- |
| admin | 平台管理员 |
| organizer | 组织者 |
| linxiao、zhou、chen | 参与者 |
| checker | 检票人员，已授权核销「校园歌手大赛」 |

数据库在 `code/data/app.db`，第一次启动自动生成。
